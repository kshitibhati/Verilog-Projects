#Verilog Projects

This repository contains various Verilog design and simulation projects created while practicing digital design concepts and RTL development.

The projects include combinational circuits, sequential circuits, counters, FSMs, buffers, encoders/decoders, and basic verification testbenches.

#Projects Included

- Full Adder
- Half Adder
- FIFO
- FSM
- Multiplexer (MUX)
- Encoder / Decoder
- Up-Down Counter
- Loadable Counter
- Shift Registers
- Digital Clock
- Arbiter
- Timer
- Tri-state Buffer
- Flip-Flop designs
- File handling examples
- Clock generation examples

#Concepts Practiced

- RTL Design
- Combinational Logic
- Sequential Logic
- Finite State Machines (FSM)
- Counters and Registers
- Clocked Logic
- Testbench Development
- Simulation and Debugging

#Tools Used

- Verilog HDL
- ModelSim / QuestaSim
- Vivado
- Git & GitHub

#Purpose

The purpose of this repository is to improve understanding of Verilog-based digital design and simulation workflows used in FPGA and ASIC development.
